# Botanika AI Pro — подробная инструкция

## 1. Что означают зелёные отметки в VS Code

- `M` рядом с файлом означает, что файл изменён после последней отправки в GitHub.
- `U` означает новый файл, который GitHub пока не отслеживает.
- Зелёная точка у папки означает, что внутри неё есть изменённые или новые файлы.

Это обычные отметки изменений, а не ошибки. Чтобы новая версия появилась на сайте, изменения нужно отправить в GitHub.

## Полный запуск системы с нуля

Выполняйте шаги по порядку. Если бот, GitHub или Vercel уже созданы, пропустите соответствующий шаг и проверьте настройки.

1. **Создайте бота.** В Telegram откройте [@BotFather](https://t.me/BotFather), отправьте `/newbot`, задайте имя и username. Сохраните username (без `@`) и секретный token. Token никому не отправляйте.
2. **Подготовьте ИИ.** Создайте аккаунт на [OpenRouter](https://openrouter.ai/), откройте **Settings → API Keys → Create Key** и сохраните ключ в менеджере паролей. Выберите модель, которая принимает изображения; бесплатная модель может быть недоступна или иметь лимиты.
3. **Создайте базу данных.** В Upstash создайте Redis и скопируйте REST URL и REST Token.
4. **Загрузите проект в GitHub.** В VS Code откройте папку `Botanika` и раздел **Source Control**. Если репозитория ещё нет, нажмите **Initialize Repository**, затем **Publish to GitHub** и выберите приватный репозиторий. Если репозиторий уже существует, выполните **Commit** и **Push / Sync Changes**. Не добавляйте `.env`, реальные токены или ключи.
5. **Подключите репозиторий к Vercel.** Импортируйте GitHub-репозиторий как проект Vercel. Если папка `Botanika` находится внутри репозитория, выберите её в **Root Directory**. Выполните первый Deploy, чтобы Vercel назначил проекту HTTPS-домен.
6. **Добавьте переменные Vercel.** В **Settings → Environment Variables** добавьте значения из таблицы в разделе **4**. В `APP_URL` укажите HTTPS-домен проекта, а в `TELEGRAM_BOT_USERNAME` — только username бота, например `BotanikaPlantHelperBot`, без `@` и без `https://t.me/`.
7. **Создайте закрытое хранилище фото.** В Vercel откройте **Storage → Create Storage → Blob**, выберите **Private** и подключите хранилище к проекту.
8. **Опубликуйте настройки.** Нажмите **Redeploy** и дождитесь **Ready**, чтобы переменные и Blob-хранилище стали доступны функциям.
9. **Подключите webhook Telegram.** В PowerShell из папки проекта запустите `.\register-telegram-webhook.ps1 -WebhookUrl 'https://ВАШ-ДОМЕН/api/telegram'`. Введите token бота и `TELEGRAM_WEBHOOK_SECRET` в скрытые поля.
10. **Проверьте ссылку и Mini App.** Откройте опубликованный сайт: кнопка **Telegram** в шапке должна вести на вашего бота. В боте отправьте `/start`, затем откройте кнопку Botanika или отправьте `/history`.
11. **Включите напоминания.** В GitHub откройте **Settings → Secrets and variables → Actions** и добавьте `BOTANIKA_APP_URL` (адрес сайта) и `SCHEDULER_SECRET` (точно такое же значение, как в Vercel). Убедитесь, что GitHub Actions включён и workflow из `.github/workflows/care-reminders.yml` находится в основной ветке.
12. **При необходимости свяжите сайт с Telegram.** В боте отправьте `/link`, введите одноразовый код в настройках сайта. Это включает синхронизацию истории, растений и фотографий между сайтом и Mini App.
13. **Проверьте систему.** Сделайте тестовый анализ в Mini App, убедитесь, что запись появилась в истории и фото открывается; проверьте ссылку на боте с сайта. Напоминание проверяйте после наступления срока полива и включения соответствующей настройки.

Подробные пояснения и решения типичных проблем приведены в следующих разделах.

## 2. Как обновить опубликованный сайт

После первоначальной настройки GitHub и Vercel обновление делается один раз — на компьютере. Не нужно отдельно загружать сайт на каждый телефон.

1. Откройте в VS Code папку проекта `Botanika`.
2. Откройте раздел **Source Control / Управление версиями** — значок ветки слева.
3. Проверьте список файлов. `M` — изменённый файл, `U` — новый файл.
4. Нажмите `+` у нужных файлов или **Stage All Changes / Подготовить все изменения**. Не добавляйте `.env` и реальные ключи.
5. Введите короткое описание, например `Update Botanika website and bot`.
6. Нажмите **Commit**, затем **Sync Changes / Push**. Если VS Code попросит войти в GitHub, войдите в свой аккаунт.
7. Откройте проект в Vercel → **Deployments** и дождитесь статуса **Ready**.
8. Откройте прежний адрес сайта. Все посетители используют этот же адрес и получают опубликованную версию; не нужно менять ссылки на телефонах.

Установленная версия сайта проверяет обновления при открытии и при возвращении интернета. Если во время обновления вы выбрали фотографии для анализа, страница дождётся завершения или удаления этих фотографий, чтобы не потерять их. Если устройство долго было выключено, просто откройте сайт после подключения к интернету.

### Если Vercel ещё не подключён к GitHub

1. Войдите в Vercel и нажмите **Add New → Project**.
2. Выберите GitHub-репозиторий с проектом и нажмите **Import**.
3. Если папка `Botanika` находится внутри другого репозитория, укажите её в **Root Directory**.
4. Добавьте переменные из раздела **4**, затем нажмите **Deploy**.
5. После успешного запуска Vercel выдаст HTTPS-адрес. Именно его используйте для сайта и webhook бота.

## 3. Что сохраняется без интернета

- История распознаваний, оранжерея и полив сохраняются в браузере на устройстве даже без сети.
- Если устройство связано с Telegram, новые и изменённые записи отправятся в облако, когда интернет вернётся. Открытые устройства проверяют изменения примерно раз в две минуты; остальные получают их при следующем открытии сайта.
- История, оранжерея и фотографии синхронизируются с Telegram, если браузер сайта связан с тем же аккаунтом через `/link`. Фотографии хранятся в закрытом Vercel Blob, а не в публичной папке сайта.
- Telegram Mini App работает отдельно от обычного сайта: в нём есть анализ фото, история с постраничной загрузкой, оранжерея и настройки языка/напоминаний. Настройки языка сайта остаются отдельными.
- Фотоанализ, энциклопедия и чат с ИИ требуют интернета. Без сети можно просматривать уже сохранённые записи и менять оранжерею.

Чтобы синхронизация работала, сайт должен быть опубликован на Vercel и связан с ботом по инструкции в разделе **6**.

Не открывайте HTML двойным щелчком из папки (`file://`), если нужны обновления, ИИ и синхронизация: этот режим не поддерживает необходимые сайту API и Service Worker. Используйте HTTPS-адрес опубликованного сайта.

## 4. Какие переменные добавить в Vercel

Откройте **Vercel → ваш проект → Settings → Environment Variables**. Добавьте переменные для окружения **Production**. Секреты не отправляйте в чаты и не помещайте в HTML или GitHub.

| Имя переменной | Где взять | Для чего нужна |
|---|---|---|
| `OPENROUTER_API_KEY` | В аккаунте OpenRouter | Фотоанализ и ответы ИИ |
| `OPENROUTER_MODEL` | `nvidia/nemotron-3.5-super-vl:free` или другая доступная модель с поддержкой изображений | Модель ИИ |
| `APP_URL` | HTTPS-адрес проекта Vercel, например `https://botanika-ai.vercel.app` | Ссылки на сайт и Mini App |
| `TELEGRAM_BOT_TOKEN` | В сообщении от BotFather | Доступ бота к Telegram |
| `TELEGRAM_BOT_USERNAME` | Username бота из BotFather без `@`, например `BotanikaPlantHelperBot` | Кнопка Telegram на сайте |
| `TELEGRAM_WEBHOOK_SECRET` | Придумайте случайную строку из латинских букв, цифр, `_` и `-` | Защита webhook |
| `UPSTASH_REDIS_REST_URL` | На странице базы данных Upstash | Адрес хранилища |
| `UPSTASH_REDIS_REST_TOKEN` | На странице базы данных Upstash | Закрытый ключ хранилища |
| `SCHEDULER_SECRET` | Длинная случайная строка | Защита планировщика напоминаний |

Нажмите **Save** после добавления каждой переменной. Если сайт уже был опубликован до добавления переменных, откройте **Deployments**, выберите последний запуск и нажмите **Redeploy**.

Чтобы создать случайный секрет в PowerShell, выполните:

```powershell
$bytes = New-Object byte[] 32
$rng = [System.Security.Cryptography.RandomNumberGenerator]::Create()
$rng.GetBytes($bytes)
[Convert]::ToBase64String($bytes).TrimEnd('=').Replace('+','-').Replace('/','_')
$rng.Dispose()
```

Для `SCHEDULER_SECRET` сохраните полученную строку и внесите её **без изменений** и в Vercel, и в GitHub Actions. Для `TELEGRAM_WEBHOOK_SECRET` создайте отдельную строку и введите её в Vercel и при регистрации webhook.

## 5. Создание Telegram-бота

### Шаг 1 — создать бота через BotFather

1. Откройте официальный аккаунт [@BotFather](https://t.me/BotFather) в Telegram.
2. Нажмите **Start** и отправьте команду `/newbot`.
3. Введите отображаемое имя, например `Botanika AI`.
4. Придумайте уникальное имя пользователя бота. Оно должно заканчиваться на `bot`, например `BotanikaPlantHelperBot`.
5. BotFather пришлёт длинный токен. Скопируйте его, но никому не отправляйте и не вставляйте в исходный код.
6. Добавьте этот токен в Vercel как значение переменной `TELEGRAM_BOT_TOKEN`.
7. Сохраните username из BotFather без `@` в переменную Vercel `TELEGRAM_BOT_USERNAME`. Он нужен, чтобы ссылка **Telegram** на сайте вела именно на вашего бота.

### Шаг 2 — создать базу Upstash для данных

1. Откройте сайт [Upstash](https://upstash.com/) и создайте свой аккаунт.
2. Создайте базу **Redis**. Название можно выбрать любое; регион желательно выбрать ближе к проекту Vercel.
3. Откройте созданную базу и найдите раздел **REST API**.
4. Скопируйте REST URL в `UPSTASH_REDIS_REST_URL`, а REST Token — в `UPSTASH_REDIS_REST_TOKEN` в настройках Vercel.
5. Не публикуйте эти значения. База хранит данные Telegram и общую историю/оранжерею сайта.

### Шаг 3 — добавить остальные переменные и опубликовать

1. В Vercel добавьте `TELEGRAM_WEBHOOK_SECRET`: случайную строку, например из букв, цифр, `_` и `-`. Запомните её — она понадобится один раз при регистрации webhook.
2. Убедитесь, что в Vercel уже есть `OPENROUTER_API_KEY` и `OPENROUTER_MODEL`.
3. Проверьте, что все переменные включены для **Production**.
4. Отправьте файлы проекта в GitHub по разделу **2** и дождитесь, пока Vercel покажет **Ready**.

### Шаг 4 — подключить Telegram к опубликованному сайту

1. На компьютере откройте PowerShell в папке проекта `Botanika`.
2. Запустите:

   ```powershell
   .\register-telegram-webhook.ps1
   ```

3. Скрипт попросит токен BotFather и значение `TELEGRAM_WEBHOOK_SECRET`. Ввод скрыт: символы не будут показываться на экране.
4. По умолчанию webhook настраивается для `https://botanika-ai.vercel.app/api/telegram`. Если ваш адрес отличается, укажите его:

   ```powershell
   .\register-telegram-webhook.ps1 -WebhookUrl 'https://ВАШ-АДРЕС/api/telegram'
   ```

5. Откройте бота в Telegram и отправьте `/start`. Проверьте меню, затем отправьте фото растения.

Если PowerShell сообщает, что адрес недоступен, сначала проверьте, что последний деплой Vercel имеет статус **Ready** и адрес в команде совпадает с адресом проекта.

### Шаг 5 — открыть Mini App

1. В `APP_URL` укажите настоящий HTTPS-адрес Vercel без завершающего `/`, сохраните переменную и заново опубликуйте проект.
2. Отправьте боту `/start`. В меню появится кнопка открытия приложения; `/history` тоже откроет Mini App.
3. Кнопки в чате достаточно для запуска Mini App. Если хотите отдельную кнопку в профиле бота, настройте **Main Mini App** через BotFather и укажите тот же адрес; для меню чата используйте `/setmenubutton`.

Mini App полностью переведён на русский, английский и узбекский. Остальные поддерживаемые языки сохраняются для бота и ответов ИИ, но интерфейс Mini App для них пока отображается на английском.

### Шаг 6 — подключить закрытое хранилище фотографий

1. В Vercel откройте проект → **Storage** → **Create Storage** → **Blob**.
2. Создайте Blob-хранилище с режимом доступа **Private** и подключите его к проекту. Убедитесь, что подключены нужные окружения, как минимум **Production**.
3. Не делайте фотографии публичными и не добавляйте токен Blob в HTML или GitHub. Vercel подключает доступ к серверным функциям проекта.
4. Опубликуйте проект заново. Новые фото бота, Mini App и связанного сайта будут сохраняться в закрытом хранилище. Старые записи, для которых прежняя версия не сохраняла файл фотографии, могут отображаться без фото.

### Шаг 7 — включить ежедневные напоминания

1. Откройте настройки репозитория GitHub → **Secrets and variables → Actions → New repository secret**.
2. Добавьте `BOTANIKA_APP_URL` со значением адреса сайта, например `https://botanika-ai.vercel.app`.
3. Добавьте `SCHEDULER_SECRET` с тем же значением, которое задано в Vercel. Используйте длинную случайную строку и не публикуйте её.
4. Убедитесь, что GitHub Actions включён, а файл `.github/workflows/care-reminders.yml` находится в основной ветке репозитория. При необходимости вручную запустите workflow **Botanika care reminders** через вкладку **Actions**.
5. Пользователь включает напоминания в Mini App. Планировщик проверяет растения каждые 30 минут и после 09:00 по часовому поясу пользователя присылает одно сообщение в день, пока полив не отмечен. Доставка может быть немного позже 09:00.

## 6. Связать сайт с ботом и синхронизировать данные

Связать нужно каждый браузер/телефон отдельно. Для всех устройств используйте один и тот же Telegram-аккаунт.

1. Откройте своего бота и отправьте команду `/link`.
2. Бот покажет одноразовый код. Он действует **10 минут** и используется один раз.
3. На устройстве, которое хотите подключить, откройте сайт Botanika и нажмите ⚙️ **Настройки**.
4. Найдите раздел **Синхронизация с Telegram**, вставьте код и нажмите **Подключить**.
5. Убедитесь, что появилось сообщение о подключении. Повторите шаги 1–4 на других ваших устройствах.
6. Проверьте: добавьте растение в оранжерею на сайте, затем откройте календарь в боте. Изменения полива также должны появиться на сайте.

Кнопка **Отключить** отвязывает только текущий браузер. Она не стирает уже сохранённые общие данные и не отключает другие устройства.

## 7. Если что-то не работает

- **Сайт не обновился:** проверьте, что изменения отправлены в GitHub, а Vercel показывает **Ready**. На устройстве закройте и снова откройте страницу после подключения к интернету.
- **Бот молчит:** проверьте переменные Vercel, адрес webhook и последний деплой. Если вы меняли токен бота, повторно запустите скрипт регистрации.
- **Код связи не принимается:** отправьте боту `/link` ещё раз и введите новый код в течение 10 минут.
- **Данные пока не появились на другом устройстве:** подключите его к интернету и откройте сайт; открытая страница также обновляет данные примерно раз в две минуты.
- **ИИ не отвечает:** проверьте `OPENROUTER_API_KEY`, лимиты аккаунта OpenRouter и доступность выбранной модели.
- **На сайте нет кнопки Telegram:** добавьте в Vercel `TELEGRAM_BOT_USERNAME` без `@`, проверьте правильность username и выполните Redeploy. На странице, открытой через `file://`, API-кнопка не работает.
- **Фото не открываются или не сохраняются:** проверьте, что к проекту Vercel подключено Blob-хранилище с режимом **Private**, затем выполните новый деплой.
- **Mini App не запускается:** проверьте `APP_URL` и HTTPS-адрес. Если вы настраивали дополнительную кнопку приложения, проверьте её адрес в BotFather. Открывайте приложение кнопкой бота, а не файлом HTML.
- **Напоминания не приходят:** проверьте секрет `SCHEDULER_SECRET` в Vercel и GitHub Actions (значения должны совпадать), секрет `BOTANIKA_APP_URL`, включённый workflow и наступивший срок полива.
- Фото, чат с ИИ и энциклопедия не работают без интернета. Сохранённые ранее записи и изменения оранжереи останутся на устройстве и синхронизируются после подключения.

## 8. Безопасность и хранение

- Не загружайте `.env` в GitHub. Файл `.env.example` содержит только примеры имён переменных.
- Не отправляйте токены BotFather, OpenRouter и Upstash в сообщения или скриншоты.
- Архив Mini App и закрытые фото хранятся в Vercel Blob и Upstash без автоматического срока удаления. Общая история сайта синхронизирует не более 30 последних записей; Mini App хранит архив с постраничной загрузкой.
- Удаление анализа удаляет его из архива и удаляет фото, если оно больше не используется растением в оранжерее.
- Общая история и оранжерея хранятся в Upstash, пока вы не удалите базу. Контекст чата и настройки Telegram-бота хранятся отдельно с 90-дневным сроком хранения, который обновляется при сохранении состояния бота.
- Публичный сайт с ИИ может расходовать лимит OpenRouter. Проверьте лимиты и использование в аккаунте провайдера.
